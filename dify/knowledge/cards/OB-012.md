# profile 叫 seekdb，驱动仍叫 oceanbase

## 梗图

画面：门铃上写着 seekdb，屋里的名牌仍是 OceanBase 向量驱动。
台词：容器是轻量版，环境变量没换姓。

## 冷知识

Dify 1.10.1 的 compose 有独立 seekdb 服务：镜像 `oceanbase/seekdb:latest`，profile 名 `seekdb`，端口 2881，健康检查是在容器里用 mysql 执行 `SELECT 1`。同版本 `.env.example` 写明 seekdb 是 OceanBase 的轻量版，共用 OceanBase 那套连接配置；`VECTOR_STORE` 的取值是 `oceanbase`，没有单独的 `seekdb` 向量类型。

环境变量说明：https://github.com/langgenius/dify/blob/1.10.1/docker/.env.example
