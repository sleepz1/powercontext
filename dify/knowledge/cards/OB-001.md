# 一条 SQL，四种检索一口锅

## 梗图

画面：向量、全文、标量和 SQL 四根箭头插进同一口锅。
台词：别人的 RAG 是拼盘，这口锅一锅出。

## 冷知识

seekdb README 把混合检索写成一条 SQL。示例同时用 `l2_distance`、`MATCH(content) AGAINST(...)`，再加上 `author_id`、`created_at` 这类标量条件，放进同一个执行计划，不在客户端做 N+1 归并。那是示例查询，不是仓库里预置的一张 `docs` 表。
