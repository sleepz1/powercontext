# 一条 pip，或者一杯 7 天的云

## 梗图

画面：左边一只 Python 蛇咬着安装包，右边一杯标着 7 天的云。
台词：本地一条命令，云上先尝一周。

## 冷知识

seekdb README 的 Python 入口是 `pip install -U pyseekdb`。同一个 README 把云上体验写成向 `https://d0.seekdb.ai/api/v1/instances` 发 POST，并注明免费 7 天。
