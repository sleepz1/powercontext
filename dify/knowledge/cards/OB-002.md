# MySQL 协议，但是能嵌进进程

## 梗图

画面：一只海豚从数据库进程里探出头，手里还拿着 ACID 四张扑克。
台词：协议是熟脸，引擎不是外挂。

## 冷知识

seekdb README 写明它兼容 MySQL 协议、提供完整 ACID，可以当作嵌入式库、单机服务器，或跑在 OceanBase 分布式集群里。LangChain、LlamaIndex、Dify 按这条 MySQL 协议对接。
