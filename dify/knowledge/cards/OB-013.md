# 牌进库之后，表名是可以算出来的

## 梗图

画面：一张卡被压进四列格子：id、vector、text、metadata。
台词：梗在 text 列里，向量只是门牌。

## 冷知识

Dify 1.10.1 的 `OceanBaseVector` 建表列是 `id`、`vector`、`text`、`metadata`。向量索引类型写死为 HNSW，距离 L2，构建参数 M=16、efConstruction=256，搜索参数 efSearch=64。这些是这段代码里的常量，不是 seekdb 的全局默认。首次建库时，集合名由默认前缀 `Vector_index`、去掉横线的 dataset id 和 `Node` 拼成后再转小写，也就是 `vector_index_<uuid>_node`。混合检索默认关闭；打开时还要求版本不低于 4.3.5.1，才会给 `text` 加 FULLTEXT。
