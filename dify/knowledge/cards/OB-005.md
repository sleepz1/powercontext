# 写入先回家，索引在后面追

## 梗图

画面：事务提交的人已经进门，HNSW 索引还在门口系鞋带。
台词：人先回来，鞋带异步系。

## 冷知识

seekdb 中文 README 描述写入路径提交即返回，索引由 Change Stream 异步消费 redo 来建。两级 HNSW（增量与快照）让新写入的向量可以被查到，而不是干等整库重建。
