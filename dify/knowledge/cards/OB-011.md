# 元数据库终于能说 MySQL 了

## 梗图

画面：Dify 的招牌从「只认 PostgreSQL」翻到三块牌子：PostgreSQL、MySQL、OceanBase。
台词：1.10.1 起，元数据不必非穿 Postgres 马甲。

## 冷知识

Dify 1.10.1 的讨论帖（2025-11-26）把 MySQL 元数据库写成该版的基础设施变化，并点名 OceanBase 团队的 PR #28188。帖子列出的元数据库是 PostgreSQL、MySQL、OceanBase。
