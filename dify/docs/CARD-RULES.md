# 牌面规则

一张牌是 `knowledge/cards/` 里的一个 Markdown 文件。文件名等于 `card_id`。

## 字段

| 字段 | 含义 |
| --- | --- |
| `card_id` | `OB-` 加三位数字，全牌库唯一 |
| `rarity` | `R`、`SR`、`SSR` |
| `theme` | `seekdb`、`oceanbase`、`dify`、`contest` 之一 |
| `keywords` | 逗号分隔。玩家原话命中关键词、主题或卡号才算抽中 |
| `source_title` / `source_url` | 冷知识的公开出处。`source_url` 以 `https://` 开头 |
| `# 标题` | 卡名 |
| `## 梗图` | 必须含「画面」和「台词」。文字梗，不外链图片 |
| `## 冷知识` | 只写出处里有的事实。数字、版本、协议不改写 |

文件里不要出现连续两个空行。知识库按分隔符 `\n\n\n`、最大长度 2000、重叠 0 分段时，一整个文件应落成一块，`card_id` 和冷知识留在同一次召回里。

## 抽卡

玩家原话先经 `rewrite_main`：

- 「再来一张」「换一张」「再抽」「下一张」「再来」记为重抽。
- 先认 `SSR`，再认 `SR`，再认独立的 `R`。
- 去掉口令和稀有度之后若没有剩词，视为泛抽。泛抽的检索词是「OceanBase seekdb Dify 冷知识」。泛抽并且在重抽、会话里又有上一主题时，检索词改用上一主题。
- 其余原话原样拿去检索。

`pick_main` 只读召回片段：

- 片段里没有 `card_id`，不出牌。
- 泛抽按卡号排序。指定了主题词时，只留关键词、主题或卡号命中的牌；一张都没命中就不出牌，也不让模型现编。
- 纯重抽且会话里有主题时，只留该 `theme` 的牌。
- 指定了稀有度就再滤一层；这个稀有度一张都没有时，保留原候选并在卡面注明。
- 只要候选里还有别的牌，就排除 `last_card_id`。
- 卡面的冷知识、梗图和出处逐字来自片段。主持人节点只能在卡面之外加两行吐槽。

同一套函数在 `scripts/cardlib.py`，并由 `scripts/render_dsl.py` 写进 DSL 的两个代码节点。改规则后运行渲染脚本，`scripts/check_deck.py` 会核对提交的 YAML 与函数一致。

本地抽卡看的是全牌库。Dify 只在知识库召回的 `top_k`（当前 8）里抽。纯重抽时，两边都在候选里按卡号排除上一张后取最小的一张。召回没有覆盖全牌库时，线上卡号可以不是本地的下一张。
