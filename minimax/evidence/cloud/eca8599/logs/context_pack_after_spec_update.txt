# Spec: Refund Eligibility (v2 — updated)

## Goal
Decide whether a completed order may receive a refund.

## Rules
1. Orders with `status == "CANCELLED"` are **never** refundable.
2. An order is refundable only when `age_days <= 7` (day 7 is **inclusive**).
3. An order with `amount <= 0` is never refundable.
4. Status comparison is case-sensitive against uppercase enum values: `PAID`, `CANCELLED`, `REFUNDED`.
5. **NEW in v2:** Orders with `status == "REFUNDED"` are never refundable again.

```python
"""Refund eligibility helper (intentionally incomplete for AE-02 demo)."""

from __future__ import annotations

from typing import Mapping, Any


def is_refund_eligible(order: Mapping[str, Any]) -> bool:
    """Return True when the order may be refunded.

    Current implementation is incomplete relative to
    specs/refund_eligibility.md (missing CANCELLED guard;
    exclusive age bound).
    """
    amount = order.get("amount", 0)
    if amount is None or amount <= 0:
        return False

    age_days = order.get("age_days", 0)
    if age_days is None:
        return False

    # BUG: exclusive upper bound; day 7 should still be eligible.
    if age_days >= 7:
        return False

    # BUG: CANCELLED orders are not rejected here.
    return True
```
